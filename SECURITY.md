# Security policy

This is a portfolio project that uses synthetic data only. It contains no credentials, endpoints, or data from any real organization.

If you find a security issue in the code (for example a sharing, CRUD/FLS or injection weakness), please open a GitHub issue without sensitive details, or contact the author through LinkedIn: <https://www.linkedin.com/in/khaja-m-ansari-a96235226>

Never commit secrets. Local secrets belong in an untracked `.env` file or in a Salesforce Named Credential / External Credential.
